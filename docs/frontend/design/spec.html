09治理速查

规则说明
新颜色必须有出处能回答"从哪个基色派生"，否则不准进代码 / 设计稿
暗色零特例.dark 只许重定义基色；暗色不对修配方，不加 override
同语义同 token次级文字只有 ink-body(fg-60) 一个名字
第二次出现即上提重复的样式组合必须抽成 packages/ui 组件
财务色 ≠ 状态色涨跌用 finance-up/down，错误成功用 error/success，色近义不近
